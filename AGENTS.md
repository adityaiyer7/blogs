# AGENTS.md

This repository keeps its agent instructions in a single, model-agnostic file:

**➡️ Read [`agent_instructions.md`](agent_instructions.md) before making any change.**

This file exists only so that tools which auto-load `AGENTS.md` find their way
there. It is a pointer, not a second source of truth — do not add rules here.
`agent_instructions.md` covers branch naming, commit and PR conventions, the
design-doc requirement, the testing policy, and which parts of the repository
are generated rather than authored.

It also indexes the supplemental instruction files (marimo, citations) that
apply to specific kinds of work.
